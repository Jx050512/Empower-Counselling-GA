# Empower Counselling — WMD1413 Group Assignment

English-language demonstration of the Empower Counselling full-stack website for WMD1413 Web Development and Design.

## Project components
- `public/` — Visitor-facing responsive website and Netlify Functions
- `admin/` — Separate administration interface

## Live demo
- Public: https://empower-counselling-limbenson-kuching.netlify.app/
- Admin: https://empower-counselling-limbenson-admin.netlify.app/

## Technology
HTML5, CSS3, JavaScript, Netlify Functions, and Netlify Blobs.

## Setup and security
Refer to the environment-variable template files in each component. Configure credentials and session secrets privately in Netlify environment settings; never commit real credentials.

This repository is for the English-language academic demonstration and is separate from the Chinese-language client deliverable.
