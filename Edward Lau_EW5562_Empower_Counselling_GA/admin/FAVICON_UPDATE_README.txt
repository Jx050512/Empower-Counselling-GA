Empower Admin - Favicon Update

This package keeps the current Admin API proxy/login fixes and changes the browser tab icon to the Empower green-person + red-heart logo.

Deploy with:
  DEPLOY_ADMIN.bat

Admin URL:
  https://YOUR-GA-ENGLISH-ADMIN-SITE.netlify.app/

If the old icon is still visible after deployment:
  1. Close the old browser tab.
  2. Reopen the Admin URL.
  3. Or press Ctrl+Shift+R / test in an InPrivate window.
