# Empower Counselling Public Website — English GA Version

This is the English public website for Empower Counselling Consultancy Services. Website content can be maintained through the paired Admin website.

## Main Features
- Home, About, Counselling Services, Programmes & Events, Resources and Contact pages
- Face-to-face counselling location with Google Maps preview and navigation
- WhatsApp contact and booking enquiries
- Online appointment request form
- General enquiry form
- Programme search, filters and sorting
- Responsive desktop, tablet and mobile layouts
- Admin-to-public content synchronisation
- Appointments and enquiries stored with Netlify Blobs; Supabase is not required

## Content Managed from Admin
- Website and contact information
- Home-page guidance section
- Counsellor profile and photo
- Counselling services
- Programmes and events
- Appointments and enquiries: view, search, filter, sort, update status and delete
- Video resources
- Media library
